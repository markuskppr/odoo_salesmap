Sales Map Lite

Revenue on a map -- installable as a ZIP, no server restart required.

No Python code No new models Apps > Import Module Multi-company safe LGPL-3

Sales Map Lite turns your existing sales orders and invoices into a live choropleth map: countries worldwide, NUTS 1/2 regions for Europe, with drill-down. It ships as a pure client-side module -- no Python code, no new models, no database migration -- which is exactly what lets it install through Apps > Import Module on hostings that do not allow a server restart.

Features

Choropleth map with drill-down

Countries worldwide, NUTS 1/2 for Europe. Click a region to see its figures and jump straight into the underlying customers, sales orders or invoices.

Figures from your own data

Reads live from the standard reporting models (account.invoice.report / sale.report) as the logged-in user, so access rights, record rules and multi-company isolation apply exactly as they already do elsewhere in Odoo.

Invoiced or order intake, always labeled

Switch the revenue basis with one click. Net amounts, company currency, document-date exchange rates -- and the dashboard always states which basis and which address (invoice, delivery, commercial parent) produced the figures on screen.

Rankings, period slider, comparison

Regions, countries, cities and customers, ranked. A period slider with playback, and one-click comparison against the previous period or the same period last year.

Nothing gets silently dropped

Revenue that cannot be placed on the map (missing country or coordinates) is reported visibly in a coverage warning, never just left out of the totals.

Data-quality audit page

A dedicated page lists every customer with revenue next to exactly the fields the map placement depends on -- country and coordinates -- with the incomplete ones surfaced first.

How it works, technically

  • Boundary geometries ship as static files: Natural Earth (Public Domain) for countries, Eurostat GISCO NUTS 2021 for the European regions. No PostgreSQL extensions, no external mapping service, no data leaves your instance.
  • Customer-to-region matching is a point-in-polygon test against each contact's geocoded coordinates, computed in the browser.
  • Nothing is stored: every figure is recomputed on the fly from your existing sales/invoicing data, so it can never drift out of sync with it.
